# Exercise tip English audit

**Status:** authoring workflow approved; exercise-by-exercise draft not started.  
**Audience:** owner training-content review before Polish translation.

## Purpose

Create one concise, exercise-specific English technique cue for every canonical
exercise, using the tone and practical specificity of the original eight plans.
This document becomes the human review ledger; the exercise library remains the
runtime source of truth after approval.

## Two visible sources

The workout always displays:

1. plan/slot-specific guidance first, in the stronger plan-related color;
2. general exercise technique guidance second, in a distinct quieter color.

No text labels are required. A plan may explicitly suppress the general cue only
when showing both would be misleading.

## General-tip content rule

A general tip should normally contain one to three of:

- the setup detail most likely to change the movement;
- the execution cue that prevents the common invalid rep;
- the intended ROM or end position;
- the primary safety/quality stop condition;
- a progression constraint intrinsic to the exercise.

Do not put plan phase, weekly load, prescribed RIR, set count or special test-day
instructions in the general tip. Those belong to plan/slot guidance.

## Voice

- Direct and specific.
- Short enough to read between sets.
- Use concrete anatomy/setup language rather than motivational filler.
- Preserve the owner's original coaching voice where an existing cue is sound.
- Do not make medical, rehabilitation or fake biomechanical-certainty claims.

## Audit columns

The generated audit table should contain:

| Field | Meaning |
|---|---|
| Exercise ID | Canonical stable ID |
| English name | Current display name |
| Pattern | Expanded canonical pattern |
| Existing general cue | Current library text, if any |
| Legacy/plan sources | Original notes or variant tips worth preserving |
| Proposed general cue | Codex-authored English draft |
| Decision | Pending / approved / revise / suppress |
| Owner note | Review feedback |

## Authoring sequence

1. Normalize exercise IDs and variants.
2. Extract all current library tips, setup notes, legacy plan notes and variant
   tips into the audit ledger.
3. Detect duplicates, generic boilerplate and plan instructions misplaced in the
   general library.
4. Draft missing English tips by pattern/equipment family while keeping every cue
   exercise-specific.
5. Review potentially risky or ambiguous movements separately.
6. Owner audits English training content.
7. Apply approved English cues to the seed/remote library.
8. Write and review Polish translations.
9. Verify 100% coverage and runtime precedence.

## Review groups

Review in manageable batches:

1. squat and knee-dominant;
2. hinge, hip extension and hamstring curl;
3. horizontal/vertical press and chest isolation;
4. vertical/horizontal pull and pullover;
5. delts, arms and forearms;
6. calves, adduction/abduction and trunk;
7. carries, calisthenics, mobility/access and unusual methods.

Each batch should be committed only after approval so rejected coaching language
never becomes an implicit translation source.
