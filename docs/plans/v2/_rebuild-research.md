Findings-only. Seeded the post-audit rebuild questionnaire. **Those questions
are now answered** (`_effectiveness-questions.md`); the implementer index is
`_audit-closeout.md`. This file does not authorize code.

Locked Wave 1 rebuilds (`_effectiveness-questions.md`) still stand; this file

## How to use this

Seven levers. Each section: what shipped, what is boring or mismatched, and
**candidates** (swap / add option / new SKU / leave). Systemic load is the
constraint on adding work — high-week plans swap, they do not stack.

Proposed question ids for the next chat round: `RB-V` variety, `RB-R` reps,
`RB-T` techniques, `RB-P` progression, `RB-I` identity, `RB-F` frequency,
`RB-M` tempo (M = metronome).

## 1. Exercise variety

### What shipped

229 library ids. Concentration: cable triceps **22/36** plans, incline DB **20**,
ab wheel **18**, hack-calf / laterals / leg-ext / hack squat **17**. Week-1
Jaccard: Monolith × Event Horizon **0.88**, EH × Oracle **0.85**, REDLINE ×
Iron Clock **0.85**, Chimera × Oracle **0.74**. Distinctiveness is histogram +
engine, not the pool.

Nine muscles still have no adequate loader: soleus, tibialis anterior, direct
adductors, direct erectors, upper/lower traps, serratus, isolated upper pec,
thin rectus femoris. Duplicate ids still split history (seated ham curl ×2,
goblet squat ×2, RDL ×2, hammer curl ×2).

### Constraint: systemic

Do **not** add axial compounds to weeks already ≥140: Iron Clock 159,
Purgatorio 151, King 148, Pencilneck 147, Gravity 145, P&G 144, Bench D. 139.
Those plans **swap** accessories or replace a hinge with a machine.

Low-axial weeks can afford a real compound if identity wants it: Kali 15,
Arms 15, Workhorse 15, Gravity 15 (already calisthenics), Cathedral 19,
Skeleton 9, Blackout 31.

### Swap candidates (same slot cost, better uniqueness or coverage)

| Current staple | Why swap | Better pick | Where it pays | Systemic note |
|---|---|---|---|---|
| Cable triceps extension (22 plans) | Catalog wallpaper | Overhead cable / JM / rolling / dip | Keep on Arms Race; swap off Monolith, EH, Oracle, Chimera, Workhorse, Foundry | Isolation; no axial change |
| Incline DB (20) | Same press everywhere | Weighted dip, deficit push-up, machine decline, landmine | Clone cluster (Monolith/EH/Oracle/Chimera) keep **one** incline SKU | Moderate; dips > DB if weighted-BW T-23 is fixed |
| Ab wheel (18) | Default core | McGill curl-up, dead bug, side plank, cable crunch, suitcase | High-axial plans drop wheel (lumbar) | Wheel is axial-ish; plank is cheaper |
| Hack-squat calf (17) | Soleus still uncovered | Seated calf (soleus) + one standing | Pencilneck, Monolith, Kali | Cheaper than adding a hinge |
| Leg extension (17) | Quad wallpaper | Reverse Nordic (after attribution fix), sissy, adductor/VMO | Quadfather keeps ext; Monolith/EH swap one | Reverse Nordic is knee-ext, not extra hinge |
| Lateral raise (17) + cable lateral | Same delt | Y-raise (true lower trap), lean-away, seated, face-pull | Overhead Dominion keeps laterals; clone cluster swaps one to Y-raise | Isolation |
| Seated ham curl (two ids, 16+9) | Merge ids first | Lying curl / GHR / Nordic / SL RDL as the **second** slot | King already decided a picker; apply to Lazarus/EH | Nordic is cheap systemic, high local |
| Hip-supported DB DL (12) | Fake hinge | RDL, 45° back ext, reverse hyper | Only if the plan is not already hinge-taxed | King keeps Fri DB DL (locked) |
| Hammer chest / hammer row / pulldown | Machine clone-band | Chest-supported row, meadow row, pullover, pec-deck | Differentiate Oracle vs Chimera vs EH | Machines keep axial down — good on high-week plans |

### Underused library to inject (coverage, not volume)

`loaded-ankle-rock` (tibialis; currently misfiled as calves), seated hip
adduction / Copenhagen, Y-raise, wall-slide (serratus/lower trap), farmer /
suitcase (erectors + grip; Atlas already has carries), reverse hyper, belt
squat if it exists, face-pull / cuff ER (King locked face-pull).

### Clone-cluster rule (RB-V1)

Monolith, Event Horizon, Oracle, Chimera should not share 20+ ids. Pick a
**house movement** per SKU, e.g.:

- Monolith: machines + drop-set finishers (already closest)
- Event Horizon: region-swap list actually different from Monolith when wired
- Oracle: keep the prediction overlay; change 4–6 accessories
- Chimera: trap-bar + quality tags; drop the EH accessory twins

REDLINE vs Iron Clock: same density pool. If both stay, one should be
lower-body density and one upper, or one 3-day and one 4-day — not two
copies of 20X0 8–12 machines.

## 2. Rep-number variety

### Boring (week-1)

| Plan | Problem | Identity excuse? |
|---|---|---|
| **Pencilneck** | **100% of 36 slots are 3 sets.** Reps vary (8–12 through 20–30) but every movement is the same set count | No. Intermediate neck/upper should mix 2-set burns and a heavy 4 |
| **Purgatorio** | **24/24 slots are 10–15.** Set count is the identity (19 fours) but every exercise lives in one rep band | Weak. Accumulation vs intensification should move reps, not only rest/tempo |
| **Venus Rising** | 21/27 slots **8–12** | Weak. Glute/physique can keep 8–12 on the job lift and 12–20 / 15–25 on isolations |
| **Kali** | 23/28 **8–12** | Cut plan can stay moderate, but anchors vs burns should split (3–6 vs 12–20) — Unleashed weeks already hint at this |
| **Athena** | 24/28 **6–10** | Partial identity (powerbuilding). Still flat. Command phase already moves primaries to top-set — accessories stay 6–10 |
| **Arms Race** | **81% 3-set** | Arms spec can be 2-set myo + 4-set pump; 3-across-the-board is the Pencilneck disease |
| **Workhorse** | 72% 3-set | Chin-up job lift should not share set count with rear-delt fly |
| **Peachy** | 67% 3-set | Glute spec: heavy 5–8 hinge/squat vs 12–20 abduction is already in the file — lean into it |
| **Monolith** | 65% 3-set | Beginner can be simple, but last-slot drop-set already exists — make set counts 2/3/4 by role |
| **Ritual** | 100% 3-set on 9 slots | **Yes** — MED 3×. Do not “spice” this |

### Already interesting (leave)

Blackout (all 1, RP), Iron Clock (4-set density + mixed reps), REDLINE (1–2
density, 13 rep strings), Neural (1 / 6 / accessories), Tenfold (10× then
collapse), P&G (10×6 + 4–6), Trinary (1–3 / 2–3 / 8–12), Bench D. (giant,
AMRAP, failure, 3–5), Atlas (carries in seconds), House (AMRAP + timed
holds), The Minimum (no 3-sets at all).

### Rule to propose (RB-R1)

Every non-MED plan assigns **roles** with different set × rep:

- Anchor: 3–5 or 4–6 or % work
- Builder: 6–10 / 8–12, 3–4 sets
- Pump / burn: 12–20+, 2 sets ± technique

Bodybuilding weeks may **add sets over phases** (MEV → MAV) instead of
starting at Pencilneck 91. That is the volume lever, not “3×10 forever.”

## 3. Intensifying techniques

### What the type system allows

`drop-set`, `rest-pause`, `myo-reps`, `cluster`, `partials`, `one-and-half`,
`tempo`, `total-reps`, `back-off`, `wave`, `amrap-finisher`,
`last-set-failure`.

### What actually ships

| Kind | Who uses it | Honest? |
|---|---|---|
| **last-set-failure** | Default wallpaper: EH, Chimera, Oracle, P&G, Tenfold, OHP, Foundry, Quadfather, Cathedral, Workhorse, Gravity, Neural, House, Lazarus, Arms (tiny), Immaculate | Cheap. Fine on isolations. Overused as the only spice |
| **myo-reps** | Arms Race (phase), Quadfather burn, Cathedral phase, Kali Unleashed II (2 slots) | Good, rare enough |
| **drop-set** | Monolith late phase only | Good. Pencilneck **banners** drop/RP on compounds in cycle 2 but that is a string, not `IntensityTechniqueSpec` |
| **rest-pause** | Kali Unleashed I (2 slots). Blackout is RP **as the set count**, not the spec | Underused as a structured kind |
| **partials** | Cathedral one slot | Unique — keep |
| **wave** (technique) | King squat, OHP weeks 9–10 | Display vs math still broken on King (T-3) |
| **total-reps** | Gravity chin/dip (audit: badge, tracking dead T-24) | Do not copy until wired |
| **cluster / one-and-half / amrap-finisher / back-off-as-technique** | **Zero plans** | Available chrome nobody used |

Bench Domination giant sets are `giantSetConfig`, not the technique union.
Super Mutant past-failure week is RIR-wave copy, frozen by the write-path.

### Candidates (RB-T)

- **Do not** sprinkle last-set-failure onto every remaining isolation.
- Pencilneck: convert the banner string to real `drop-set` / `rest-pause`
  specs; isolation last-set-failure already applied in preprocess (and
  isolations drop to 2 sets — so week-1 “36×3” is the authored template,
  not always the live isolation count).
- Cathedral already has the richest mix (LSF + partials + myo) — template
  for other spec plans.
- Unused kinds worth a home: `cluster` on Neural or Trinary DE (speed
  clusters), `one-and-half` on Peachy glute bridge / King goblet, `amrap-finisher` on Kali/REDLINE instead of dead recovery.
- Advanced only: rest-pause / myo / drop. Beginners (Minimum, Skeleton,
  House, Apex, Monolith early): double progression, no intensifiers until
  a late phase.

## 4. Week-to-week progression

### What shipped

Most `definePlan` hypertrophy: **`type: 'double'` +2.5 kg** when all sets
hit the top of the range. No RIR. No weekly RPE wave.

Exceptions:

| Plan | Model | Gap |
|---|---|---|
| Ritual / Trinary | RPE ME, streak jumps (locked) | Velocity checkbox → RPE already decided |
| P&G | RPE on deficit; % on others | Locked deloads 8+12 |
| King | % + broken wave | Locked bench rebuild; still no RIR on accessories |
| Bench D. | AMRAP → e1RM checkpoints | No RPE on accessories |
| Neural | % 1-6 | Overload = Charge % (T-63); no RIR |
| Athena | Double → top-set-backoff by phase | No RPE/RIR on accessories |
| Venus | Double + **phase RPE 8.5 / 9.5 / 8** | Best BB-ish RPE wave; week-1 scan is 0 because RPE lands in later phases |
| Lazarus | **RPE 7 on every Waking slot**, set cap | Best returner model. Memory Curve dead |
| Oracle | Calibration **RPE 8** + requires RIR in copy | Scoring half dead; prediction half live |
| Event Horizon / Minimum / Chimera | Double; late **RPE 9** on non-compounds | RPE as a late-phase hammer, not a weekly language |
| House | Double + one push-up RPE 8 | Beginner-simple — OK |
| Super Mutant | RIR 2→1→0→past-failure | Dead until writes persist |
| Blackout | RecoveryResponse (shared engine) | Wired for Blackout; REDLINE copy is dead |
| Iron Clock | Density ladder | Unused; falls to +2.5 |
| Pencilneck / Tenfold | Bespoke double / gated double | No RIR. Tenfold has a hidden 10% collapse |

`linear` and `totalReps` progression types are essentially unused as the
week driver.

### Proposed catalog rule (RB-P1)

- **Powerlifting / neural:** RPE on the job lift (already the PL lock).
  Accessories can stay double or get RIR 2–3.
- **Bodybuilding / physique / spec:** **RIR** on working sets (target RIR
  3 early → 2 → 1 in a late intensification), not a fake RPE 9 stamp on
  every isolation in week 8.
- **Beginner / return / constrained:** keep **double progression** + optional
  “stop 2 reps shy” in notes. Lazarus RPE 7 and House AMRAP-with-reserve
  are the templates. Do not put RIR logging on Skeleton/Minimum unless
  the UI is one tap.
- **Volume progression** is allowed instead of load: add a set every 2–3
  weeks on builders (MEV→MAV), especially 3-day conversions and Pencilneck
  if it stays “intermediate.”

Plans that need a progression language most (none today besides double):
Pencilneck, Peachy, Arms Race, Workhorse, Foundry, Quadfather, Cathedral,
Monolith, Kali, REDLINE, Purgatorio, Immaculate, Chimera.

## 6. Frequency — 4-day saturation, 3-day default, 2-day expansion

### What shipped (`portfolio.ts` frequency)

- **4-only:** ~20 plans (Pencilneck, Peachy, P&G, King, Gravity, Purgatorio,
  Immaculate, OHP, Foundry, Arms, Workhorse, Neural, Tenfold, Kali, REDLINE,
  Quadfather, Cathedral, Monolith, EH, Chimera, Oracle, Bench D. matrix-4
  but audit 4–6).
- **3-only:** Skeleton, Apex, Lazarus, Blackout, Atlas.
- **3 and 4 already coded:** Venus, Athena, Iron Clock, Trinary (cap).
- **2 and up:** Adventure, House of Iron.
- **2-only:** The Minimum.
- **Ritual** listed 5–6, audit **3**.

Athlete reality: 3-day is the common split. The product defaulted to 4.

### Convert existing (add 3-day via the Athena/Venus `scheduleMode` pattern)

Prefer this over new SKUs when the week is a 4-day U/L or spec that can
drop the lightest day.

| Plan | Why 3-day | How (systemic) |
|---|---|---|
| **Monolith** | Beginner tagged, 4-day 103 | Merge to 3× full-ish; start ~60–70 sets, add a set on builders |
| **Pencilneck** | 4-day 147 is the identity failure | 3-day **and** MEV start (~12–16 sets/muscle) then climb. Or stay 4-day but ramp from ~50 sets |
| **Peachy** | Glute spec, beginner tag | 3-day: two lower + one upper; keep hinge dose, drop a press day |
| **Cathedral** | Lightest spec (89) | 3-day push/pull/chest still hits pec frequency |
| **Kali** | Cut; 4-day 77 | 3-day makes the cut *more* Kali. Keep one systemic anchor/session |
| **Arms Race** | Arms don’t need a fourth day | 3-day: push (arms), pull (arms), legs+arms |
| **Workhorse** | Chin spec | 3-day: heavy chin, volume chin+legs, horizontal |
| **Event Horizon** | Clone; adaptive story | Offer 3-day on **EH or Oracle, not both** |
| **Quadfather / Foundry / OHP** | Spec frequency | Optional 3-day: keep the two spec days + one maintenance |

**Do not flatten to 3-day:** Tenfold (10× needs days), Purgatorio (pair
split), Gravity (four job days), Neural (four neural days), Bench D.
(frequency is the product), King/P&G (locked), Iron Clock (already has
3-day — **lead with 3-day as default**), REDLINE (density 4-day or new
3-day SKU, not a silent trim).

### Already 3-day — leave as the 3-day spine

Blackout, Atlas, Lazarus, Apex, Skeleton, Ritual (honest 3). Trinary stays
flexible.

### 2-day expansion (RB-F2)

Do **not** force King or Pencilneck into 2 days. Add or fork:

1. **Skeleton 2-day option** — user request. Two full-body sessions, MEV,
   same exercise pool, double progression. Late phase can add a third day
   rather than jumping 57→72 sets on three days.
2. **The Minimum** stays the 2-day gym MEV. Do not clone it.
3. **New SKU: 2-day strength maintenance** — squat/bench/hinge + 2
   accessories, RPE, ~45 min. Fills the hole Ritual doesn’t (Ritual is 3
   hard days). House is dumbbells; this is barbell.
4. **New SKU: 2-day physique ramp** — A/B full body, start ~8–10 sets per
   muscle/week, add a set every 2 weeks. Not Pencilneck-lite.

House of Iron already covers 2/3/4 dumbbell. Adventure covers 2/3/4
random. That is enough “flexible” — new 2-days should be **named jobs**.

### Volume rule (RB-F3)

Do not constrain a bodybuilding card to a fixed weekly set count. 3-day
Monolith can start near MEV and add sets in weeks 4–8. Pencilneck must not
open at 91. Iron Clock must not open at 108 if the 3-day is the default.

## 7. Tempo where it matters

### What shipped

- **20X0 default** on 20 `definePlan` programs (5,279 slots). Unreviewed.
  Includes Blackout and The Minimum.
- **No tempo** on most % / conjugate / Pencilneck / Bench D. / House /
  Foundry (except 40X0 curls) / Tenfold (except 40X0) / Trinary / Atlas
  (except 10X0 primaries).
- **Meaningful exceptions:** King 12X0 paused squat (matches copy), 11X0
  paused bench; Purgatorio **30X0 house**; Foundry/Tenfold/Gravity **40X0**
  on selected ecc work; Neural 10X0/11X0 on the 1-6; Atlas 10X0 primaries;
  Peachy one 11X0.

### Rules to propose (RB-M)

1. **Strip default 20X0** from plans that don’t mean it. Empty tempo ≠
   “no control”; it means athlete-chosen. Keep 20X0 only where we want a
   2s eccentric on that slot.
2. **Powerlifting speed / CAT:** concentric-intent tempo, e.g. `X0X0` or
   `10X0` with a note “fast up, no bounce.” Trinary DE and King CAT
   (locked) should show this, not 20X0. P&G 10×6 @ 45% is speed-ish —
   `10X0` or `X0X0`, not a grind.
3. **Paused work:** tempo must match the pause (King 11X0/12X0 is the
   gold standard). Spoto/pin already named — don’t also 20X0 them.
4. **Bodybuilding ecc variety (cheap uniqueness):** one isolation per
   day at `30X0` or `31X0` instead of adding a new exercise. Candidates:
   Pencilneck laterals, Peachy hip thrust ecc, Cathedral pec-deck,
   Monolith leg ext, Arms Race curls. Purgatorio already *is* 30X0 —
   intensification should **speed up** (20X0 or 10X0) so the block
   contrast is real.
5. **Do not** 40X0 a squat or DL on a high-axial week (King, P&G, Atlas,
   Chimera). 40X0 stays on curls, hamstrings, chins (Gravity/Foundry).

Tempo-as-technique `{ kind: 'tempo' }` is unused; slot `tempo` is enough.
Don’t duplicate.
