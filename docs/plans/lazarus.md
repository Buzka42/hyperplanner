# Lazarus

Eight weeks, three-day full body, for a previously trained athlete returning
after at least three months away. Onboarding records the break duration, prior
experience, and whether an injury caused the break.

The Memory Curve shows two points: the lifetime best and the last *stable*
pre-break performance. Prescription always comes from the second, discounted
for time away — 90% under three months, 80% to six, 70% to twelve, and 60%
beyond, where the curve flattens rather than pretending to extrapolate.

Exact and close-variation history prescribes directly. Anything further away
opens lighter and requires calibration, as does any self-reported number. With
no usable memory the first working set is simply a calibration set.

Weeks 1–2 are capped at two sets per slot. The cap is applied in the program
tree *and* reasserted at session build, so a rerun, a swap or an admin edit
cannot reintroduce the volume. Feeling ready does not lift it — that is the
state that produces a week-3 injury.

From week 3, two clean sessions inside a rolling window where the prescription
was clearly an underestimate accelerate progression. One session is noise.

Where an injury caused the break, the plan states plainly that it is not
rehabilitation, points at a trainer or physiotherapist, and suggests Apex
Predator after a long absence. It does not model the injury.

Verification: `npm run verify:lazarus`.
