# REDLINE

Eight-week, four-day full-body plan built for 40–50 minute sessions. Every
session is one heavy anchor at full rest, then paired burn work, then optional
timed finishers.

Each day carries 12–16 prescribed working sets outside the finishers. Burn
slots are always paired (A1/A2, B1/B2 …) and alternated; a pair without its
partner is a straight set wearing a stopwatch and fails verification.

The Furnace anchor is a persistent choice between Paused Bench and Standing
Overhead Press, selected once per run and stored in plan preferences.

Finisher windows run 5 minutes in weeks 1–2, 6 in weeks 3–5, 7 in week 5, 8 in
weeks 6–7, and return to 5 in week 8. Work logged after a window expires counts
as training but never improves density.

A recovery answer precedes each session. It only takes effect once confirmed:
`somewhat fatigued` trims burn sets, `performance impaired` also drops the
finishers, and the anchor always survives. The reduction is visible and
reversible.

Week 8 (Ashes) cuts burn volume to roughly two thirds rather than reducing
intensity.

Verification: `npm run verify:redline`.
