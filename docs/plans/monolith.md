# Monolith

Ten weeks, four days, upper/lower, machine-dominant. Roughly three quarters of
the slots are machine or cable work; the rest stays free-weight where that is
the better tool. Barbells are not banned to make the theme hold.

Sessions run 16–22 sets with at most one systemic anchor each, and every day
mixes bilateral and unilateral execution. The plan uses the known fixed gym
inventory, so there is no per-run machine selection.

Progression order is deliberate: place the work (weeks 1–3), then raise effort
(weeks 4–6, RPE 9 on non-systemic slots), and only then add technique — a single
20% drop on the last set, and only on machines where taking that alone is safe.
Week 10 sheds a set per slot.

Machine Press/Fly Combo has its own history, separate from both Chest Press and
Pec Deck, and the two never appear in the same session. Any pairing that would
require crossing the gym floor is stripped at session build; a superset across
that distance is a rest period with extra walking.

Verification: `npm run verify:monolith`.
