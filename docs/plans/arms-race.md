# Arms Race

Eight weeks, four days a week, of biceps and triceps specialisation. The
concept doc's one hard rule is that four weekly arm exposures must differ in
function and loading, so they do: a heavy day (close-grip bench and straight-bar
curl, 5x4–6, three-minute rests, double progression), a brachialis and
reverse-grip day, a lengthened-positions day (incline lying curls, overhead
extensions), and a density day run as paired supersets with 30-second rests on
the A1/B1 sides. Everything that is not an arm stays at twice weekly, sharing
days with the arm work.

Progression only exists on the two heavy lifts; every other slot is held at
fixed sets and reps and the user progresses them by feel inside the rep range.

Phases are a single mid-plan shift. Weeks 1–4 (Escalation) run the spec as
written. Weeks 5–8 (Proliferation) add one set to every arm slot — detected by
superset pairing or by curl/pressdown in the exercise id — while non-arm work
holds, so the added fatigue lands exactly where the plan is named for and
nowhere else.
