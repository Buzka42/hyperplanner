# Atlas

Ten weeks, three days a week, run as two five-week gauntlets. Five weeks is long
enough to get good at a movement set; the second gauntlet then changes the
pattern rather than the page layout, and the movement set is stable inside each.

Gauntlet one: Safety-Bar Squat, Trap-Bar Deadlift, Standing Barbell Press,
Weighted Pull-Up, unilateral legs, rows, trunk, grip and carries. Gauntlet two
keeps the qualities and changes the movements — front squat, single-arm standing
press, rotational rows, step-ups.

The hinge is the athlete's choice among Trap-Bar, Conventional and Sumo
Deadlift, selected once per run. An unapproved choice is ignored rather than
applied.

Carries are trained as a lift. The metric is `time × load` — kilogram-minutes,
counting both implements — so a heavier short carry and a lighter long one are
directly comparable. Each week has one main carry and two shorter exposures.

The optional limiting-factor tag (grip, trunk, breathing, upper back, legs) is
the useful part of a carry log. The same limiter twice in a row earns specific
advice: add a suitcase hold for grip, shorten the interval for the trunk, extend
gradually for breathing. It is advice — the carry is never rewritten
automatically.

Kettlebell swings, kettlebell shoulder presses and Turkish get-ups are available
as optional power work. They are absent from the prescription entirely, so they
can never become required or drive progression.

Verification: `npm run verify:atlas`.
