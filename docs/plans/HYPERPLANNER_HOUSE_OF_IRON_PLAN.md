# HOUSE OF IRON
## HyperPlanner Minimal-Equipment Home Training Plan

**Status:** Training-design baseline before implementation specification  
**Primary goal:** full-body hypertrophy and general strength using one dumbbell or one kettlebell  
**Format:** four selectable workouts — Push A / Pull A / Push B / Pull B  
**Frequency:** flexible, recommended 3–4 sessions/week  
**Equipment:** one dumbbell or one kettlebell; optional pair unlocks swaps but is not required  
**Audience:** beginner/intermediate users training at home or with minimal equipment  
**Cycle length:** 8 weeks, repeatable

---

# 1. Core Identity

> **ONE WEIGHT. FOUR ROOMS. BUILD THE HOUSE.**

HOUSE OF IRON is the minimal-equipment HyperPlanner plan.

Its promise is simple:

- no gym required;
- no full rack of dumbbells required;
- one dumbbell or one kettlebell is enough;
- four distinct sessions;
- flexible scheduling;
- progression remains possible even when external load cannot increase.

This should not feel like a generic bodyweight home workout.

The defining problem is:

> **How do we continue progressing when the athlete owns only one fixed load?**

The answer is a progression ladder based on:

1. reps;
2. sets where appropriate;
3. range of motion;
4. pauses;
5. eccentric duration;
6. 1.5-rep methods;
7. unilateral variations;
8. finally, heavier equipment.

---

# 2. Schedule Philosophy

The user sees four selectable session cards:

- **PUSH A**
- **PULL A**
- **PUSH B**
- **PULL B**

The plan is not locked to Monday/Tuesday/etc.

Recommended frequency:

- **3 days/week:** minimum useful schedule
- **4 days/week:** recommended
- **5 days/week:** allowed only if balance and recovery rules are satisfied
- avoid repeatedly selecting the same session

HyperPlanner should recommend the next workout using recent history.

Example:

```text
Recent:
Push A
Pull A
Push A

Recommended next:
PULL B
```

The recommendation is advisory rather than mandatory.

# 3. Balance Rules

HOUSE OF IRON should quietly track four broad training qualities:

- Upper Push
- Upper Pull
- Knee-Dominant Lower
- Hip-Dominant Lower

Dashboard example:

```text
THIS WEEK

UPPER PUSH        2 ✓
UPPER PULL        1 ⚠
KNEE DOMINANT     2 ✓
HIP DOMINANT      1 ⚠
```

Recommendation logic should prefer the workout that restores balance.

The user can still choose another workout.

# 4. Workout Design Rule

Each workout has two headline muscle-group priorities while still contributing to full-body weekly frequency.

The four sessions:

## PUSH A
**Chest + Quads**

## PULL A
**Back + Hamstrings**

## PUSH B
**Shoulders + Quads/Glutes**

## PULL B
**Back + Glutes/Hamstrings**

This creates a basic push/pull identity without letting a muscle disappear for an entire week.

Target:

**12–15 working sets/session**

Home sessions should remain efficient.

# 5. PUSH A — Chest + Quads

## Main 1 — Goblet Heel-Elevated Squat
**3×8–15**

Equipment:
- one DB or KB

Purpose:
- quads;
- glutes;
- trunk.

Progression options:
- reps;
- deeper ROM;
- 3-sec eccentric;
- 1.5 reps;
- eventually skater squat progression.

## Main 2 — Single-Arm Floor Press
**3×8–15/side**

Purpose:
- chest;
- triceps;
- anterior delts;
- anti-rotation.

Progression:
- reps;
- pause on floor;
- longer eccentric;
- glute-bridge floor press if appropriate.

## Secondary 1 — Bulgarian Split Squat
**2×8–15/side**

Rear foot can use:
- couch;
- chair;
- bed edge.

If setup is unavailable:
- reverse lunge.

## Secondary 2 — Push-Up
**2×AMRAP with 1–2 RIR target**

Progression:
- regular;
- deficit;
- feet elevated;
- slow eccentric.

## Secondary 3 — Single-Arm Overhead Triceps Extension
**2×10–20**

## Optional Core — Suitcase Hold
**1–2×30–60 sec/side**

**Total: 12–14 sets**

---

# 6. PULL A — Back + Hamstrings

## Main 1 — One-Arm DB/KB Row
**3×8–15/side**

Support hand on:
- chair;
- couch;
- table edge if stable.

Progression:
- reps;
- longer stretch;
- pause at top;
- slower eccentric.

## Main 2 — DB/KB Romanian Deadlift
**3×8–15**

If one implement becomes too light:

progress toward:
- staggered stance;
- B-stance;
- single-leg RDL.

## Secondary 1 — DB/KB Pullover
**2×10–20**

Performed on floor or suitable bench/couch setup.

Purpose:
- lats;
- serratus;
- long-ROM shoulder extension.

## Secondary 2 — Single-Leg RDL
**2×8–15/side**

Use support for balance if necessary.

## Secondary 3 — Curl
**2×10–20**

Options:
- standard curl;
- hammer curl;
- concentration curl.

## Optional Carry — Suitcase Carry / March
**1–2 rounds/side**

**Total: 12–14 sets**

---

# 7. PUSH B — Shoulders + Quads/Glutes

## Main 1 — Single-Arm Standing Press
**3×6–12/side**

Alternative:
- half-kneeling single-arm press.

Progression:
- reps;
- pause overhead;
- controlled eccentric;
- stricter stance.

## Main 2 — Goblet Skater Squat
**3×6–12/side**

Regression:
- supported skater squat;
- reverse lunge.

This is a key HOUSE OF IRON progression movement because one fixed load can remain challenging for a long time.

## Secondary 1 — Single-Arm Floor Press
**2×10–15/side**

Use a different rep target than Push A.

## Secondary 2 — Sissy Squat / Supported Sissy Squat
**2×10–20**

If unsuitable:
- heel-elevated goblet squat.

## Secondary 3 — Single-Arm Lateral Raise
**2×12–25/side**

Only practical when implement is light enough.

If the available implement is too heavy, substitute:
- bodyweight wall-lean lateral isometric;
- controlled partial raise;
- optional band only if user owns one.

## Secondary 4 — Close-Grip Push-Up
**1–2×AMRAP**

**Total: 13–14 sets**

# 8. PULL B — Back + Glutes/Hamstrings

## Main 1 — Staggered-Stance / B-Stance RDL
**3×8–15/side emphasis**

## Main 2 — One-Arm Row Variation
**3×10–20/side**

Different from Pull A through one of:

- elbow path;

- pause;

## Secondary 1 — Weighted Glute Bridge
**3×10–20**

- bilateral;

- single-leg;
- 1.5 reps.

## Secondary 2 — Pullover
**2×12–20**

## Secondary 3 — Rear-Delt Row
**2×12–20**

Use a lighter/more controlled style than the main row.

## Secondary 4 — Hammer Curl
**1–2×10–20**

**Total: 14–15 sets**

# 10. Fixed-Load Progression Ladder

The app should not repeatedly tell a user with one 16 kg kettlebell:

> Add weight.

Instead every exercise should have a progression ladder.

## Level 1 — Rep Progression

Reach the top of the prescribed range on all sets.

## Level 2 — ROM Progression

Increase usable range of motion.

Examples:
- deeper split squat;
- larger deficit;
- longer stretch.

## Level 3 — Pause Progression

Add:
- 1-sec;
- then 2-sec pause

at the difficult or lengthened position.

## Level 4 — Eccentric Progression

Move from normal cadence to:

- 3 sec eccentric;
- potentially 4 sec.

## Level 5 — 1.5 Reps

Use only on suitable movements:

- squat;
- split squat;
- glute bridge;
- selected presses.

## Level 6 — Unilateral Progression

Examples:
- bilateral RDL → B-stance → single-leg;
- bilateral glute bridge → single-leg;
- goblet squat → supported skater squat.

## Level 7 — Density Progression

Complete equivalent work with slightly less total block time where safe.

## Level 8 — Equipment Upgrade

Only after the movement has genuinely outgrown the existing implement should HyperPlanner suggest:

> A heavier bell would now be useful.

# 11. Eight-Week Structure

## Weeks 1–2 — FOUNDATION

- establish variations;
- 2–3 RIR;
- standard tempo;
- learn balance system.

## Weeks 3–4 — BUILD

- 1–2 RIR;
- progress reps;
- introduce pauses on exercises that hit rep ceilings.

## Weeks 5–6 — HARDEN

- priority movements use stricter tempo/ROM progression if load is capped;
- selected final isolation sets can approach 1 RIR.

## Week 7 — HOUSE ON FIRE

- hardest normal week;
- selected safe movements use 0–1 RIR final sets;
- no reckless failure on unilateral squats/RDLs.

## Week 8 — REBUILD

- reduce work by roughly 30–40%;
- maintain exercise difficulty;
- record end-of-cycle performance;
- offer another cycle with harder progression levels.

# 13. One-Weight Problem Detection

If the user repeatedly exceeds the top rep range by a large margin at low effort:

Example:

```text
Target: 8–15
Actual: 20, 20, 19 @ 3+ RIR
```

HyperPlanner should not simply add more reps forever.

Trigger:

> **THIS MOVEMENT HAS OUTGROWN YOUR LOAD**

Then progress to:
- harder leverage;
- longer ROM;
- unilateral version;
- slower tempo.

Only after all useful options are exhausted recommend heavier equipment.

---

# 14. Recommendation Engine

The next-workout recommendation should consider:

1. last session;
2. push/pull balance;
3. knee/hinge balance;
4. whether a session was completed within the previous ~24–48 hours;
5. repeated selection of the same workout.

Simple priority example:

```text
if pullCount < pushCount:
    recommend least-recent Pull workout
elif kneeCount > hingeCount:
    recommend Pull B or Pull A
else:
    recommend least-recent workout
```

Do not make HOUSE OF IRON as complex as Super Mutant.

This is a lightweight recommendation system.

Approximate:

**35–50 minutes**

# 17. Swaps

Swaps must remain genuinely home-compatible.

Do not offer:

- cable machine;
- hack squat;
- leg extension;
- machine press;

inside HOUSE OF IRON.

Swap metadata should consider:

- one implement;
- floor;
- chair/couch;
- optional wall;
- optional sturdy table/support.

Base promise must remain truthful.

---

# 18. Safety / Setup Guardrails

Because users train at home:

- never require unstable furniture for load-bearing support;
- chair/couch support should be optional rather than mandatory;
- do not prescribe movements requiring improvised overhead anchors;
- avoid improvised pull-up setups;
- unsupported users should receive floor-based alternatives.

# 21. App-Native Mechanics

HOUSE OF IRON should have four signature systems:

## 1. Equipment Profile
Knows what implement and load the user owns.

## 2. Balance Tracker
Tracks push/pull and knee/hinge exposures.

## 3. Next-Workout Recommendation
Suggests which of the four sessions best restores balance.

## 4. Fixed-Load Progression Ladder
Progresses movement difficulty when adding weight is impossible.

These mechanics justify HOUSE OF IRON as an app program rather than a printable home routine.

3. Which floor/chair-supported exercises already exist in the exercise database?
4. How should unilateral sets be represented in total-set accounting?
5. Should the progression ladder be manually authored per exercise or generated from exercise-family metadata?
6. Should Week 8 automatically recommend the next harder variation for Cycle 2?
