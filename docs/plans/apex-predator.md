# Apex Predator

**Program ID:** `apex-predator` · **Source:** [src/data/plans/apexPredator.ts](../../src/data/plans/apexPredator.ts)
**Duration:** 12 weeks · **Frequency:** 3 full-body days/week (dow 1, 3, 5)

## Overview

Movement-access-driven full body. Base tree includes `apex-access-placeholder` slots filled by `applyApexAccess` from assessment results. Six optional measured regions; retests weeks **4, 8, 12** (volume cut). Optional suitcase carry. See also [apex-assessment-guide.md](apex-assessment-guide.md) and `npm run verify:apex`.

## Phases & week-to-week progression

### Stalk (1–3) / Adapt (5–7) / Apex (9–11)
Full base volumes; access slots resolved from latest assessment.

### Hunt retests (4, 8, 12)
Week 4/8: all slots `sets = min(sets, 2)`.
Week 12: sets ≥3 or lateral-raise → 2; else 1.

## Techniques, supersets, finishers

- Double progression on main compounds.
- Access work injected at preprocess; optional carry.
- Default tempo `20X0`.
