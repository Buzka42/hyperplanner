# Tenfold

Eight weeks of four days (Mon/Tue/Thu/Fri) derived from German Volume Training.
Exactly one exercise per session runs the ten-set format — 10 sets of 10 at
90 seconds rest with a 40X0 tempo — and it always goes first. Everything else
is ordinary accessory work of 3-4 sets, which is what keeps the plan
survivable while still giving every major muscle two weekly exposures.

The four days each carry one focus: chest (hammer chest press), quads (hack
squat), back (hammer lower row), hamstrings (seated ham curl). The quad and
hamstring days smuggle in the second weekly exposures for the other muscle
groups, since each focus muscle only gets one ten-set day.

Progression is not weekly weight increases. The load is held constant until
all ten sets reach ten reps; only then does weight go up. Weeks 6-8 are a
consolidation phase that converts the ten-set block to eight sets of 8-10 —
ten sets of ten cannot run for eight straight weeks, so the back half trades
a set for a rep range and lets the load finally move.
