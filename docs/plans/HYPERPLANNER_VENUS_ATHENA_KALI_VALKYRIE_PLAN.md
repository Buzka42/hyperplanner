# HyperPlanner — Venus Rising / Athena / Kali / Valkyrie

## Design status

This is the programming and product-design baseline before writing the implementation brief for Claude.

The four programs form one connected female-oriented progression branch:

**Venus Rising → Athena → Kali → Valkyrie**

Users do not have to follow the path linearly. Valid routes include:

- Venus → Valkyrie
- Venus → Athena
- Athena → Valkyrie
- Athena → Kali → Valkyrie
- Venus → Athena → Kali → Valkyrie

The shared system should allow later plans to use performance history from earlier plans.

---

# 1. Global rules

## Venus and Athena schedule modes

Both plans must support:

- **3 days/week:** full-body training
- **4 days/week:** Upper / Lower ×2

The 3-day version is not a reduced "lite" plan. The weekly intent remains similar, but volume is distributed more efficiently.

## Session set cap

For both Venus and Athena:

- target **15–16 working sets per session**
- avoid routinely exceeding 16
- do not force mathematically identical weekly set counts between 3-day and 4-day modes
- preserve the goal, muscle frequency and progression rather than cramming four days of work into three sessions

If a phase would exceed the cap:

1. preserve the primary movement;
2. preserve priority-muscle work;
3. preserve minimum muscle/movement frequency;
4. remove the lowest-priority isolation set first.

## Time-efficient exercise philosophy

Prefer exercises with high stimulus-to-time value:

- Hack Squat / Heel-Elevated Squat
- FFE Bulgarian Split Squat
- Reverse Lunge / Goblet Skater Squat
- Hip Thrust
- Hip-Supported DB Deadlift / DB RDL
- Leg Curl
- Leg Extension
- chest-supported / Hammer rows
- Pulldown / Pull-up
- Machine Chest Press / DB Press
- OHP
- Lateral Raise
- single-arm rear-delt machine work

Avoid redundant chains of similar exercises.

Example of unnecessary redundancy:

- flat press
- incline press
- machine press
- cable fly
- push-up

The 15–16 set ceiling means every exercise must justify its place.

## Frequency rule

For hypertrophy-oriented plans:

- major muscles should normally receive at least **2 meaningful weekly exposures**
- large specialization targets usually receive about **3 exposures**
- smaller specialization targets can receive **3–4**

A secondary compound contribution is not automatically counted as a full direct set.

## Supersets

Use low-interference supersets to reduce session duration.

Good:

- lateral raise + curl
- rear delt + triceps
- calves + abs
- low-fatigue core + leg curl

Avoid pairing two high-performance compounds.

# 2. Venus Rising

## Identity

**Build the physique. Learn how to progress.**

Venus is the broad female physique-development plan.

It is not Peachy 2.0.

Priority:

1. glutes
2. delts
3. back/lats
4. quads

Secondary:

- hamstrings
- chest
- arms
- calves
- abs

## Duration

**12 weeks**

### Weeks 1–4 — Foundation

- learn exercises
- establish working loads
- mostly 2–3 RIR
- moderate volume

### Weeks 5–8 — Rising

- slightly greater priority-muscle stimulus
- mostly 1–2 RIR
- continue double progression

### Weeks 9–11 — Ascension

- highest effort of the cycle
- final sets of selected safe isolation movements may reach 0–1 RIR
- no complicated intensification methods

### Week 12 — Rebirth

- roughly 60–70% normal volume
- keep reasonably challenging loads
- selected rep-PR opportunities
- finish recovered

# 5. Venus set progression

Do not grow the plan by continually adding exercises.

### Weeks 1–4
Use base templates.

Approximate direct/effectively-primary weekly workload:

- glutes: 9–10
- delts: 7–8
- back/lats: 8–9
- quads: 7–9
- hamstrings: 5–6
- chest: 4–5
- arms: 3–4 each

### Weeks 5–8
Add about one weekly set to selected priority areas by converting a 2-set priority exercise into 3 sets, while keeping sessions within 16.

### Weeks 9–11
Keep volume similar to Weeks 5–8 and increase stimulus through:

- more load
- more reps
- lower RIR
- selected hard final isolation sets

### Week 12
Reduce:

- most 3-set accessories → 2
- most 2-set accessories → 1

## Venus progression

Default:

**double progression**

Example:

3×8–12

When all prescribed sets reach the top of the range with acceptable technique:

**increase load next exposure.**

When load cannot increase easily:

1. add reps
2. increase ROM
3. add pause
4. slow eccentric
5. move to a harder variation

# 6. Athena

## Identity

**Master the lifts. Learn to train heavy intelligently.**

Athena is not a powerlifting program.

It teaches:

- stable technique
- heavier loading
- RIR/RPE
- top-set + back-off structure
- reliable performance tracking

It also builds a reusable performance profile for later HyperPlanner programs.

## Duration

**12 weeks**

### Weeks 1–4 — Wisdom

- main work mostly 6–10 reps
- 2–3 RIR
- technique consistency
- basic loading progression

### Weeks 5–8 — Discipline

- primary work moves toward 4–8 reps
- top sets and back-offs introduced
- mostly 1–2 RIR

### Weeks 9–11 — Command

- primary work around 3–6 reps
- slightly lower volume
- higher intensity
- no mandatory grinders

### Week 12 — Judgment / Consolidation

- reduce accessories
- preserve meaningful main-lift exposure
- save final Athena performance profile
- no mandatory true 1RM testing

# 10. Athena phase-specific set logic

Athena becomes harder mainly by changing load and rep structure, not by adding more sets.

## Weeks 1–4

Base templates.

## Weeks 5–8

Convert existing primary-lift sets into top-set/back-off structure.

Example:

Old:

**Bench 4×6–8**

New:

- 1 top set × 4–6
- 3 back-off sets × 6–8

Still **4 total sets**.

## Weeks 9–11

Potentially reduce one back-off set on the most demanding lifts.

The freed set does not have to be replaced.

## Week 12

Reduce accessory volume first.

---

# 11. Athena progression

## Wisdom

Mostly double progression:

**3–4×6–10**

Hit top reps with good technique → increase load.

## Discipline

Selected primary lifts:

### Top set
**4–6 reps @ ~1–2 RIR**

### Back-off
Reduce load about **7.5–12.5%**

Then:

**2–3×6–8**

Top set reaches upper target at acceptable RIR → increase next exposure.

## Command

Top set:

**3–5 reps @ ~1–2 RIR**

Back-offs:

**2–3×5–7**

No required maximal attempts.

# 12. Schedule switching

Venus and Athena users can switch between 3-day and 4-day mode without restarting.

Preserve:

- current week
- workout history
- working loads
- progression state
- e1RMs where relevant
- RIR/RPE history
- exercise preferences

Recommended behavior:

> Schedule changes apply from the next training week.

Avoid remapping a partially completed week unless specifically designed.

# 13. Shared schedule architecture

Do not implement four duplicated programs.

Use:

```text
PROGRAM
  ↓
PHASE TARGETS
  ↓
SCHEDULE MODE
  ↓
ALLOCATION TEMPLATE
  ↓
RESOLVED DAY
```

Example:

```text
Venus Phase 2
glutes = high
delts = high
back = high
quads = medium-high

3-day → FBW A/B/C
4-day → Lower/Upper A/B
```

The exact total weekly set number can differ slightly by mode.

# 14. Kali

## Identity

**Strip away excess. Keep the strength.**

Kali is a cutting-phase training plan.

It is not:

- cardio disguised as lifting
- very high reps because the user is cutting
- a low-intensity "toning" plan

Core rule:

> **Reduce volume before intensity.**

Main objectives:

- preserve strength
- preserve muscle
- reduce systemic fatigue
- emphasize glutes and lats aesthetically

## Duration

**8 weeks**

### Weeks 1–2 — Severance

- immediate volume reduction
- main work around 2 RIR
- accessories around 2–3 RIR
- calibrate imported loads

### Weeks 3–5 — Preservation

- main work mainly 3–6 reps
- 1–2 RIR
- hold performance while recovery is reduced

### Weeks 6–8 — Kali Unleashed

- overall weekly volume remains controlled
- glutes and lats receive hard intensification techniques
- intensifiers replace straight sets instead of being piled on top

---

# 15. Kali systemic-compound rule

Maximum:

**one systemically demanding compound per workout.**

Do not define this simply as "multi-joint."

Use metadata such as:

```text
systemicCompound: true
```

Examples likely true:

- heavy squat
- heavy conventional deadlift/RDL
- heavy barbell bench
- heavy OHP
- heavy weighted pull-up

Examples usually false:

- machine chest press
- chest-supported row
- single-arm pulldown
- machine hip thrust
- leg extension
- leg curl
- cable work
- most supported unilateral movements

Purpose:

- retain heavy loading exposure
- reduce whole-body fatigue
- keep local muscular effort high

---

# 16. Kali unilateral rule

Every workout should include at least:

**one meaningful unilateral arm or leg exercise.**

Examples:

- FFE split squat
- single-leg press
- single-leg hip thrust
- single-arm pulldown
- single-arm supported row

Benefits:

- high local stimulus with less absolute loading
- useful left/right performance data
- lower systemic cost

# 19. Kali intensification

Weeks 6–8:

Priority:

- glutes
- lats

Rule:

> **Extended techniques replace ordinary volume.**

Example:

Instead of:

3 straight hip-thrust sets + an extra rest-pause set

use:

- Set 1 straight
- Set 2 straight
- Set 3 rest-pause

or reduce to two total sets if the extended set is extremely demanding.

## Good glute techniques

- hip thrust rest-pause
- abduction myo-reps
- cable kickback dropset
- single-leg hip thrust extended set

## Good lat techniques

- single-arm pulldown rest-pause
- lat prayer myo-reps
- supported pulldown dropset
- pullover controlled dropset

## Do not intensify

- heavy squat
- heavy RDL/deadlift
- heavy weighted pull-up
- heavy free-weight press

The heavy movement is the strength-retention signal.

Stable movements are where Kali becomes brutal.

# 21. Kali load-transfer hierarchy

When Kali needs a starting load:

## 1. Exact exercise history

Example:

Machine Chest Press → Machine Chest Press

**Highest confidence**

## 2. Close variation

Example:

Barbell Bench → Hammer Chest Press

**Medium-high confidence**

## 3. Same movement family

Example:

Back Squat → Single-Leg Press

**Medium/low confidence**

## 4. Same target-muscle family

Example:

Back Squat → Leg Extension

**Low confidence**

## 5. No useful history

Run calibration.

Do not pretend an inferred machine load is scientifically exact.

Display:

**Suggested starting load**

rather than:

**Correct calculated weight**

---

# 22. Calibration set

For lower-confidence transfers:

Target example:

**8–10 reps @ approximately 2 RIR**

After set 1:

- **5+ RIR:** increase approximately 10–15%
- **3–4 RIR:** increase approximately 5–7.5%
- **2 RIR:** keep
- **1 RIR:** keep or reduce slightly
- **0 RIR / failure:** reduce approximately 7.5–10%

Then save the calibrated load as the actual user-specific starting point.

Internal transfer confidence:

- HIGH = same exercise
- MEDIUM = close variation
- LOW = related family

The user does not necessarily need to see the internal label.

# 23. Kali Preservation Index

Kali should compare current performance against the pre-cut baseline.

Possible categories:

- Squat
- Hinge
- Push
- Pull

Example:

```text
Squat: 98% retained
Hinge: 101%
Push: 96%
Pull: 99%
```

Optional bodyweight context:

```text
Bodyweight change: -4.8 kg
Average performance retained: 97%
```

The goal is not necessarily to set PRs.

The goal is to finish the cut while retaining as much capability as possible.

## Theme possibility: Kali's Four Arms

Each arm represents:

- Squat
- Hinge
- Push
- Pull

The arm remains visually "armed" while performance stays within the target retention band.

# 30. Guiding principle

These plans solve different problems:

> **Venus Rising:** build the physique.  
> **Athena:** master heavier training.  
> **Kali:** cut volume and bodyweight without surrendering strength.  
> **Valkyrie:** combine advanced strength and physique development.

The shared performance-history system is what should make them feel like one HyperPlanner ecosystem rather than four themed spreadsheets.
