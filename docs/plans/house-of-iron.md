# House of Iron

Eight-week repeatable minimal-equipment plan for one or more dumbbells or
kettlebells. Athletes freely select Push A, Pull A, Push B or Pull B; the
dashboard recommends, but never forces, the session that best restores upper
push/pull and knee/hip balance.

Required sessions contain 12–15 working sets. Optional suitcase holds and
carries do not affect completion or balance. Week 8 reduces required volume by
30–40% and offers another cycle without erasing equipment or accepted exercise
difficulty.

Two consecutive clean exposures at the top of a rep range earn an authored
fixed-load progression recommendation. The athlete explicitly accepts or keeps
the current step. Ladders use only stages suitable for that exercise family and
end with heavier-equipment advice after useful rep, ROM, pause, eccentric,
leverage/unilateral and density options are exhausted.

Verification: `npm run verify:house-of-iron` and `npm run verify:progression`.
The full implementation contract remains in
[the focused specification](specs/house-of-iron.md).
